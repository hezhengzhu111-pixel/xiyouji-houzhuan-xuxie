# 打斗调度

本书的打斗要精彩、清楚、合乎力量逻辑。精彩不等于更大、更快、更响，而是**每个强者都在做只有自己会做的判断，局势因这些判断不断改变**。

## 一、每场重要战斗的五项要件

动笔前先写清楚，缺一项就重排：

1. **双方目标**：截住谁、护住谁、逼谁移位、争什么时机、保住哪条路。只写"战胜对方"不算目标。
2. **可辨空间**：战场是御阶、宫道、云路、天门、法界内外、阵眼、册印所在还是亡魂往来的路。远近、高低、出口、可破坏的节点要具体。
3. **独有战法**：每个人用只有他会用的方法；不能换个人来使同一招也成立。
4. **有效攻守转换**：至少一次真实的反制或改势——位置、信息、阵形、能力可用性、伤势、人物判断、关系，每轮交锋至少改变一项。
5. **不可撤回的结果**：谁得到什么、失去什么、伤在哪、哪条路从此不通；结果要延续到下一场、下一回。

打完之后问：如果再打一次，起点是否已经不同？若一切与开头一样，这一战没有发生。

## 二、力量差怎样兑现

第一卷里含章只有父亲教的普通功夫和剑法。遇盗时兄妹能走到哪里、谁挡住谁，按凡人的身手和地势来写。下列神通只用于相应的后卷场面。

- 强弱差距用**战法**兑现，不用旁白宣布。陆含章可以毁天庭主阵，但李靖要先以调度改变她的推进方向；她可以重伤哪吒，但哪吒要凭近身抢势逼她第一次改变出剑；她可以击败二郎神，但二郎神要先以天眼识穿幻化部下的结构、真正逼近本体。
- 原作神佛即使注定战败，也要凭各自神通、经验和性格作出有效判断，并真实改变战局。
- 她越强，越要写她**怎样选择**：何时铺开幻化部下、何时收为一剑、何时吞断阵力、何时越过无关目标直取权柄。冷酷写在取舍与出手精度上，不靠反复写表情。
- 既定胜负只锁结果，不替代过程设计。不能把"合阵""大势"当万能解释；被毁之处不复原，诸神舍去受损部分后凭实际相接的力量调整。

## 三、人物战法速查

| 人物 | 战法重心 | 不能写成 |
|---|---|---|
| 李靖 | 军阵调度、塔的位置、收军次序、护退路与后队；根据战果改令 | 只会喊"列阵""守住"；与哪吒同一种打法 |
| 哪吒 | 近身抢势、枪圈绫围、火轮换位、为争时机弃正面；莲身旧伤影响动作 | 少年莽撞小孩；排队挨打 |
| 二郎神 | 天眼识变、指路、变化赴援、承认办法不通再改判 | 一眼看尽因果与陌生阵法；每次都用旧敌冷讽开场 |
| 悟空 | 变化、真假、远近、分身与本体互换、救人进攻随时转换、临机破局 | 只会举棒硬拼；所有缺口一人填满；被写成旧天条护法 |
| 如来 | 法界、整体空间、接总势、逼力量显出边界；守正面 | 施咒、拿旧恩当制敌机关；每次露面负责总结全卷 |
| 玉帝 | 周天星阵、册印与拘取、宫阙换守、反扑争接阵机会；下令与改令 | 永远耐心答辩；把责任推给臣下 |
| 后卷的陆含章 | 按入体、融合或明光消融时的力量写她如何用剑、吞法、破界或幻化部下 | 靠旁白威压取胜；让凡人阶段就有黑莲本领 |

## 四、三种规模交替

- **军阵**建立规模：谁守哪一段、退往何处、还能接几次阵。
- **近身**呈现人物：枪棒相接、真假换位、兵刃被卸、伤势落地。
- **法界与空间**体现神魔层次：宫阙被移、星位倒转、云路断裂、法界收缩。

三者不能长期只写一种。环境损伤要成为下一步的行动条件（断桥影响撤军、星灭影响换位），不是一次性景观。

## 五、伤势与代价

- 伤势必须有动作因果：宝塔失效来自军阵承压，莲身崩裂来自近身死战，神目受创来自识变后仍须亲自承受的一击。不能一律写成"被黑光击中后倒飞"。
- 伤者要按伤势调整动作与判断（持枪侧、能不能化形、还能不能分路撤军）；延续到同卷后续，不靠佛光一照痊愈。
- 凡人死伤、通道毁损、宫阙易手、册印来路被截，都是真实代价；不是只换一场气势。
- 第四卷要让读者看到各界的掌权之所怎样失守、败退者如何保住余力、随后如何合三界之力反击。人间号令被截断，凡人照常生活。

## 六、第四卷专门边界

- 陆含章从天庭内部突然出现，天庭没有提前发现、追踪、布防或把她逼入战斗；第一场大战由她主动发起。
- 她从天庭内部以法力幻化大量部下，沿宫道、天门铺开；部下无魂、无名、无人格，被斩散只化回黑影，不流血、不哀号，也不能成为独立政权。
- 李靖、哪吒、二郎神开场协同，先后重伤：二郎神神目受创仍在闪开后力报出险处；李靖塔被震偏、胸前受击仍传完撤令；哪吒弃正面枪势、借火轮横移抢出撤军时间，肩胸开裂。三人互救衔接，惨败但仍作出有效判断。
- 玉帝先退，灵山与其余掌权之处亦陆续失守。第三卷中生死簿已经销毁。
- 灵山之战悟空与如来可以局部反攻，护住伤者或撤军；含章可避开对悟空的强杀，夺下他们所守的发令处。三界占领必须成为事实，之后才有合力反击和含章倾尽力量分界。
- 善念抑制只在对**真正有恩、仍不愿杀死**的眼前对手强行动杀时发生；不取消护体、修复与本源位格，也不由一句"善心未灭"宣布全身法力停机。

## 七、常见坏写法

- 轮流报招：你一招我一招，招式名字轮流喊。
- 同色光芒对轰、等级播报、旁观者连续惊叹。
- 靠人物降智制造险势：名将忽然不会判断、忽然忘记旧经验。
- 临时削弱黑莲、让她忘记能力、硬造"救人还是制敌"的二选一。
- 用"无限未知""深不可测"拖延，不交代获得信息的途径。
- 把合阵的时间无限拉长来凑回数；压缩章节只剩"破阵、受伤、退走"的结论。
- 战前目标不清、空间不清，打到一半才开始解释战场是什么样子。

## 八、动笔前的六问

1. 这一战谁要什么，输了会失去什么？
2. 空间里哪些东西可争、可毁、可断？断了之后谁的路变了？
3. 每个人各自只能怎么打？换个人来使同一招还成立吗？
4. 第一次有效反制由谁完成，代价是什么？
5. 这一战结束时，哪一项与开始时一定不同？
6. 伤势、位置、关系怎样带进下一场？
