# 时间连续性

## 第〇至二十回已写稿所见（待作者审定）

| 时间、回次 | 前后相接的事 |
|---|---|
| 无天覆灭之夜；此后三十年（〇） | 如来归位，悟空受封。元神黑莲落涧；三十年以后，陆家秋收时添了女儿。序中最后一个春日含章五岁，景和比她大五岁。短序与正卷分列 |
| 七岁、九岁、十三岁（1—3） | 七岁春，兄妹蒸面燕；两年后随父正式学剑；十三岁的春天，她凭自己争到哥哥的一截衣袖。兄妹在灯下把话说开时，还未到那次赴邻集的山路上 |
| **同年二月十八、三月廿五**（4—5发生，14揭晓） | 二月十八阎罗已为陆衡、沈素、陆景和发牒。三月廿五一家四口赶集，傍晚归途在白石坳遇盗。两日同年，先发令、后拔刀；含章不在当日拘取名单里。陆家人赶集时对此全不知情 |
| 入谷第一年暮春、夏、秋、冬（6—8） | 暮春黄昏坠潭，当夜首次在岩棚生火。夏汛过去、石脊干后才攀岩，归途中伤左腿。入冬尚须拄杖，闻山背吆喝，赴缓坡举烟求救，无人回应 |
| 入谷第二年到满两周年的暮春（9—10） | 第一个春天扶杖到溪边；又过一夏一秋一冬，能独自往返岩棚与水潭。第二次山花开、连雨漫棚，退水后发现石隙。到约十五岁，选另一处浅岸再下水。第十回最后只见花 |
| 与第十回同一刻起（11—13） | 托莲入体、上崖取剑、回棚取物、去看西岸三座坟。次日起找行凶者，当日仇报，入晚归家。随后由寿终老人看到阴差如何开界，才自行入幽冥。悟空卷后从本源重现的痕迹追到此处 |
| 阎王殿至昆仑山口（14—17） | 阴司先认三魂同入蒙界，后验两处日期、领令押字及末行朱押。含章立收据取原牒，悟空代送御前，复带原件与答复回来。她要求玉帝亲答；清出亡魂、撤兵、剑棒两次交接、三方转移去向，才到昆仑 |
| 入山第一日、十七日（18） | 初到，能吃能睡，开得出界却不能离山。十七日借剑影排除日照，首次确实分辨明暗相接、两者仍各自在原处。没有新得明光 |
| 第四十九日起至七十日前（19） | 四十九日写悟空在幽冥查三魂，经蒙界踪迹亲自辨认、听取口信。由寻访到回灵山再问如来跨了若干日，三人仍留蒙界，不能把本回所有事压成四十九日当天 |
| 第七十日（20） | 山门隔界传来三人各自的话。含章亲自演给悟空看，收回暗力，明光仍留在石与手相接处。离山日期未定。此处是第二卷待审稿终点 |

## 后两卷规划

- **昆仑第八十一日**（21）：此前没有人能保证光暗会合。含章融合后自己开界。第二十二回毁掉生死簿，第二十三回才同次为三人重塑肉身。
- 玉帝准一家安居一年，三人在人间实在地过完四季，此后白莲花传达邀约，三个人的回答各不相同，再召再战。第三十回被合阵放逐时三人尚活。
- **黑暗之渊四十九日**（31）从放逐后另起，不与昆仑八十一日混算。明光彻底消逝、三人同时消逝，含章决定截断神令，继而吸收全渊暗力。回末直接出现在天庭。
- 天庭失守、悟空接伤、灵山与诸界掌权处相继陷落之后，才有三界合力反击和最终分界。第四十回悟空循边界寻人未果。尾声略去年数，不倒推出含章去向或终局年龄。
