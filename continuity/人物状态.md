# 人物状态与知情先后

## 第〇至二十回已写稿所见（待作者审定）

| 人物 | 当时能知道什么 | 到第二十回为止，自己做了什么选择 |
|---|---|---|
| 陆含章 | 十三岁看见四名山匪怎样截路，跌入潭中后不能尽信自己记得的每一步。十五岁从谈话、旧伤、父剑的鞘与亲眼所见辨清各人。复仇前不知阴司曾发令。十三回由寿终老人的去路进幽关，十四回才知道三魂在蒙界、三人此前已奉令必拘 | 她原能先去灰坡寻亲，却签名领走原牒，托悟空替活着的人问一个答复。入昆仑后仍不肯以交出黑莲换自由。第七十日愿意把明暗相接的情形给悟空看，由他照实带回 |
| 陆衡 | 父亲、木匠，会几手防身剑法。白石坳应允交财，出剑给妻儿让路，死在缺耳老黎短刀下。原魂仍保有自己的记忆、手艺 | 在蒙界问清悟空怎么用棒、女儿如何用剑。捎话叫女儿觉得剑柄不合手就换布，缠柄的尺寸可以由她定 |
| 沈素 | 母亲、织布人。提醒补秤的邱二躲开凿口，无意喊出称呼。她给儿女换一侧牵手，撬动滚木，自己死于邱二刀下 | 在蒙界先问女儿愿不愿进昆仑，确认口信不会被拿去劝她认错，才托悟空问如何剪面燕尾，讨下一回的翅根 |
| 陆景和 | 大妹妹五岁，已独立接木工活。买下三把窄宽不同的凿，未及向父亲当面试给他看。白石坳上回身横杠拦人，胸侧受邱二的刀 | 他末后的「好好活下去」已说完。第七十日悟空带回本人对那一刻的回答，妹妹才知道没有落掉第二句话 |
| 悟空 | 当年亲手开元神黑莲放还众魂，能认本源。近来循潭与灰窑所留的气息、行迹找到现在的持有者；只凭黑莲不能知道她是谁，更不知阎罗发过什么令 | 幽关看清她给亡魂让路，殿上等她先读牒，御前拦笔追问；他仍认可借明光消去暗力，亲自出棒拘她。第四十九日起寻三位原魂，听各人当面回话；第七十日看见两力仍各归其主，未许诺能放她出山 |
| 阎罗、崔判官与当差人 | 当差人亲历山劫、领过在先的拘令，能认签领押字；崔判官经手簿录；阎罗亲发原牒，能答若有人逃生是否仍须拘取。三者各有亲历的部分 | 崔判官让开殿前的路，阎罗示原牒、认自己的朱押，许含章立收据带走原件，也承认无神力相助的生还者照旧当拘。十九回能证三魂去向，不能代他们答复女儿 |
| 玉帝 | 看原牒承认来历，又亲笔认下山劫中没有神佛替兄妹插手。防神仙循香火、亲疏增损寿数，是他坚持保留定死期之权的理由 | 愿记救妹之善，不答应将来放过靠自己逃生者。第一次擒人时亲自停住天庭旧路，另接昆仑；没有以杀人、逃死为名命人惩罚含章 |
| 如来 | 亲察旧日白石坳，为哥哥护妹作证；与悟空、哪吒一样，有理由谨慎对待无天留下的完整本源 | 提出以昆仑明光消去暗力，亲自收合二人交战的空间。肯保她身魂安好，但至第七十日仍没有准许离山的日期 |
| 李靖、哪吒、二郎神 | 李靖知道阵脚与后队如何相接；哪吒亲见过元神黑莲，愿当面辨她的来意；二郎看得清兵阵、护魂暗力与真身交剑的位置 | 李靖退旗用塔接人，哪吒近身争路，二郎制止误击护魂之力、看准相持之处传讯。三人能让部下退出、接上合阵，不能仅凭这几手擒住含章 |
| 唐僧、敖烈 | 唐僧知道弟子赞同拘人；敖烈有泾河旧冤的家事，也见过石坳痕迹、御前答复和昆仑山门 | 唐僧追问若消融不成要拘到何日，悟空带着这问题亲问如来。敖烈能向山内与山外分说自己见过的事，不能替含章应下拘留 |

## 第二十一回以后规划

- 含章在第八十一日才有明光与黑莲相合的能力。三位亲人听清明光维系新生命的代价后，各自答应还生。陆衡赴工，沈素愿应白莲花相邀，景和要按与人试船的约定留在人间。含章曾替三人一口回绝，得亲自收回这句答话。
- 再次调兵时，唐僧可拒绝帮忙；八戒不为不知出口所在的放逐作保，悟空自己还旗补阵。渊中明光消尽，陆家三人永别。此后含章放弃谈判，攻占诸界掌权之所，始终不向普通亡魂与凡人报复。
- 悟空接伤保人、守灵山、参加三界反击，最终尊重含章亲手关闭的界限。第四十回寻找无果，尾声村中一家身份留白。
