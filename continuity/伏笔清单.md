# 故事里留下的物证与回声

## 第〇至二十回已写稿所见（待作者审定）

| 母亲剪的燕尾、给父亲剩下的两个硬嘴（1） | 实际上父母一人吃了一个。20回沈素隔山捎话，承认自己也嚼得费劲，下回想吃翅根。同样两只硬嘴，女儿记得一路惦着留给爹，做母亲的还记得嚼过好半天。听了这句话，她才像又同母亲吃过一顿饭 |

| 景和试买三把凿；含章补一文，留住半枚旧钱（4） | 5回凿子滚向邱二的脚，母亲才失口叫出称呼。6回她把半钱收进油布。11回徐家儿子拾回三凿，含章收下伤了一角的那把，其余两把仍托徐家；13回把铁器放回父亲座前。14回原牒由她签收，悟空不收半钱作保。20回半钱与缩短如针的金箍棒分搁两边，谁也没有买下另一人 |
| 山口的旧剑、旧鞘（5） | 剑进崖顶废石槽，戴笠人的杠勾去木鞘。11回凭崩落的黄石、护手补过的月牙痕找回锈剑；12回旧鞘从白灰堂木柜取回，帮助核实戴笠人的动作。13回拆见鞘内木胎裂透，把鞘料、铜扣、旧皮留在陆家木凳旁，带走的是黄布裹住的父剑。以后可换柄布，不能让完好的旧鞘随她进昆仑 |
| 一家人同带的一束织线、火镰、小葫芦（4—8） | 5回散开的纱绊敌，火镰和燧石随含章落谷。油布内层尚干的火绒救第一夜，葫芦后成为伤腿后最难够到的一样东西。她把水、柴和食物挪近，使后来养伤举烟有了实在条件。11回临行特意回棚关火、穿回补过的鞋、取回随身用物 |
| 石脊的豁口、上游到棚前的一条白石带（6—10） | 看清豁口使她肯退，那一趟没有带她出谷，却使她在第二次春汛前认出水路。她先转移食物与火种，舍掉鱼篓，退水后寻篓才注意到石隙。前后两次下潭的位置不同。11回她得莲后先要过去看的，也是这道曾经走不过的豁口 |
| 小说中先后出示的两份文书（14—15） | 山劫遇到刀兵之险与阴差必须在是日带走三人，是同一张原牒上不同的两句话。两名差役的押字、阎罗末行朱押、两处日期均可核。**原牒**由阎罗交给含章签领，悟空呈玉帝看过，原件交还含章。**御前另写的认据**承认落水生还是兄妹自己所为，不能拿来代替撤除拘人的规矩 |
| 云台断处与昆仑晒石（16—20） | 含章劈开的路能过，落点却被合阵接到昆仑。入山试界仍如此。十七日她自己遮住日光辨出太初明光；七十日让悟空亲眼看着她收手，留在石上的光未随她走。第八十一日若有变化，须让读者看见与这次不同的动作和结果 |

## 后两卷规划，写作时再兑付

- **一纸与一册。** 含章在昆仑把原牒包在油布下，另以纸笔记家人做过的事；她没有将父母哥哥缩成告示上的三名。毁簿时要截住的是阴司全册；独撕陆家一页，不能替别的活人废掉旧令。
- **谁可以替谁答应。** 当年挨着母亲自己剪燕尾，是含章的愿望。还生须让三人各自知道明光消逝的后果，各自同意。此后母亲愿去灵山，不能连带算作哥哥赴召的答复。
- **举过的烟、送过母亲的一程。** 谷底举烟时含章曾真心盼人伸手；白莲花送沈素回村，是应了沈素本人的意愿。永久分界时这条可以行善的路也要关上，须由含章自己承认代价。
- **报信与用棒是同一人做的。** 昆仑七十日的旧恩能让含章对着悟空本人下杀手时迟疑，不能使她失去护体或永远放弃进攻。当年还旗补阵的是悟空本人，往后八戒追问落处、悟空拦住借伤路进兵，都有这一次选择在先。
- **两个不可逆的结果。** 明光在渊中彻底消失，三位亲人永别；毁簿既未撤去神佛越界的本领，夺下掌权处也仍需含章亲守。直到她用尽一身力量，神力才永远不能再到人间。尾声那户人家不登记身份，也不用面孔、旧物或一句暗语指认其为陆家重归。
