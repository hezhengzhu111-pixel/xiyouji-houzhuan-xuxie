# 力量变化

## 第〇至二十回已写稿所见（待作者审定）

| 节点 | 力量落在哪里 | 看不出、办不到的事 |
|---|---|---|
| 〇、1—10 | 无天覆灭后，曾容纳众神魂魄的完整元神黑莲沉入深潭。含章跳崖时靠哥哥挡住追兵、自己选择深水、蹬水上浮。困谷的两年只用凡人的身体。第十回在石隙外看见莲花 | 黑莲未相合，不暗中护她、疗伤、引路。谷中摔伤不是换取力量的条件 |
| 11 初次接触 | 她伸手托起花萼，本源与她相合。旧伤消退，身侧暗力挡开硬枝与崖石；心念指向野梨豁口，她已越过它、到达崖顶。此后力量总量与本源位格即已超过绝大多数神佛 | 没有声音、传功、认主或无天的记忆。能跃上崖，不等于知道亲人葬在何处或谁杀了他们。找剑靠她记得黄石和旧石槽 |
| 12—13 权衡轻重 | 她能托稳翻动的船与白灰，把已知现场的人一起护住，同时收住行凶者。父剑承她法力后极难损毁，刃口细伤可缓慢自修。亲见差役以木牌开路，她能辨出阴阳道路的两线开合，自行过界。殿前托住过路亡魂，破门而门栓不到人身上 | 剑的坚韧留在剑材上；黑光、护体、护魂、御空、破界和出剑的轻重由她自己作主。自修不会还原木胎已经裂透的剑鞘。不能凭力量读出人心、死因或原牒 |
| 14—17 完整黑莲迎战 | 她能断开云台，稳住亡魂与退兵，普通天将不能正面擒她。悟空真身抵剑缩棒，赶至缺口外再接第二次；天庭停旧路、改阵脚，如来收合实战所及的空间。三处行动赶在同一次交锋上，才把人送入昆仑 | 她劈开的门仍通，跨过去落脚却只能在昆仑。没有受刑、失剑、耗尽法力或给人击穿护魂。此时未融合，此战不能拿来断定融合后一两位强者仍足以制她 |
| 18 第一日、第十七日 | 初入山，山内可行可住，可握剑试破界；整个出路仍接山内。十七日以剑影遮太阳，温光仍在。她抬暗力、收暗力，光仍照石面；以暗力拨开云，也只改变日照 | 能辨明光不等于能调动它。明光试图消暗只落在力量上，身体、元神安好，太初明光仍属山中 |
| 19 第四十九日起 | 悟空在蒙界能查访、变化分身。三人原魂各有自己的手艺与主意；他能见、能听、能传话 | 通得过蒙界不等于当下能使三人以活人肉身回家。普通外来者在蒙界仍按禁法核对 |
| 20 第七十日 | 她自愿在晒石上同悟空复看：鸟影过处，两力均在；暗力随手抬起，明光不移；暗力收回，明光仍照指侧石纹。她再次张手，只能召回自己的黑莲暗力 | 二人亲见「相接，各在」。卷末没有消融，也没有提前取得明光。悟空只能据所见向如来复述，不能据此替她许诺离山 |

## 第二十一回以后规划

| 阶段 | 必须保住的因果 |
|---|---|
| 第三卷光暗融合 | **昆仑第八十一日**，明光才随她收手并与暗力相合，从内开界。她远超其他单个强者。先毁整册，依簿强拘的权力随之失效，抄本、原牒、帝印均不能续行旧日；再以明光为尚存原魂合造肉身。自然的生老病死与亡魂往来仍在 |
| 再次交战与放逐 | 寻常神将组合或帝佛简单联手压不住融合后的她。天庭、佛门、幽冥、四海的力量实际相接，悟空自己补阵，合力改变整个战场去向，方能将她放逐。父母哥哥此时仍有真实生命 |
| 第四卷黑暗之渊 | 四十九日中先失尽昆仑明光，三人彻底消逝。她放弃谈判，决定占据诸界施令之所，随即吸收全渊黑暗，战力继续增加。黑莲护体、修复仍在，已无造身的明光；黑暗之源没有因吸收就宣告枯竭 |
| 已占领、再分界 | 她以无独立魂魄的幻兵夺权，凡人照常生活。面对有旧恩的悟空，要下杀手时主动攻势可受牵制；无法据此穿透本源防护。反击发生在占领之后，她仍能再夺渡处，却主动把维持占领在内的全部力量用于永久天人分界。分界自行成立，亡魂仍可往来 |
