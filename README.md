# 《西游记后传续写》

江南青溪村的少女陆含章，十三岁暮春白石坳遭劫失亲、跳崖困谷两载，十五岁于幽潭得无天旧莲。她握一根绝谷石缝削得的青竹竿走出深谷，从手刃血仇、闯冥问天、昆仑融光、青溪暂聚，到希望碎尽、沉渊悟暗、终战见大圣再殉，最终以自身本源复活六圣，余力化作永恒结界永断人神干涉，让人间归于天地自然。

全书共 **41 回**（第〇回序章 + 四卷四十正回），**初稿 592,767 汉字已全部完稿**，当前进入**大纲统一与全文精修阶段**。原独立尾声已并入第四十回《春风又绿渡头竹》收尾。
