# 《西游记后传》续写

陆含章生在溪边的一户人家。十三岁遇盗失亲，困谷两年；后来她得过足以占领三界的力量，最后亲手合上了神佛干预人间的路。全书四卷四十回，第〇回与尾声另列。正回平均约一万五千字，预计约六十万字。
